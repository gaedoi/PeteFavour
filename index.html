MAP LIBRARY

Add maps downloaded from BeatSaver (.zip files, or an unzipped map folder). They are saved in this browser. Then download a copy of this game with every map built in, so it works offline and on GitHub Pages.

Drop .zip files here or

Smaller option for GitHub Pages: upload the HTML without maps as index.html, then upload your BeatSaver .zip files to the same repo (the root, or a folder called maps). The game finds them on its own. Other web hosts: add a maps.json file listing the zip names.

AUDIO TO MAP

Pick a song file. The game listens to it, finds the beat and builds a map with 5 difficulties and a light show.

Maps play in Pete Favour with any of these audio types. The real Beat Saber game only accepts .ogg audio, so use an .ogg file if you also want it there.
